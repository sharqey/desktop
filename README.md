# Sharqey Desktop

Desktop app for [Sharqey](https://sharqey.com), the end-to-end encrypted
password manager for teams. Your keys stay on your device; the server only
stores encrypted data.

- Sign in to [app.sharqey.com](https://app.sharqey.com) or your self-hosted Sharqey server.
- Use local `.sharqey` databases without an account.
- Unlock with Touch ID, fill logins through the [browser extension](https://chromewebstore.google.com/detail/sharqey-password-manager/hkiigjjakecaebakedhhlhfaobfpjmge).

## Download

Get the latest version from [Releases](https://github.com/sharqey/desktop/releases/latest).
macOS builds are signed and notarized. Windows and Linux are coming.
